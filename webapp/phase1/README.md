# GIEN Governance Webapp — Phase 1

WP-096 established the briefing template, evidence model and initial regulatory research. WP-098 hardens the evidence contract, metric semantics and regulatory source register.

- evidence-drawer.schema.json: version 1.1.0 observation and digest contract
- metric-definitions.v0.2.0.json: twelve metrics with explicit directionality or unresolved status
- regulatory-source-register.v0.2.0.json: primary source records and effective dates
- oscal_crosswalk_seed.json: internal 24-control crosswalk seed, not a native OSCAL Catalog
- test_phase1_contracts.py: focused contract regression tests

All GIEN indices remain provisional simulation constructs. Crosswalk mappings are not legal opinions or compliance determinations.
