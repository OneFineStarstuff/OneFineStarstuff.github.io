# AI Governance: Regulator Demonstration & Rehearsal Plan

## 1. Phase 1 Demonstration Agenda (90-Minute Regulator Version)

*   **(0-10 min) Introduction & Sandbox Goals**
    *   Welcome and introductions.
    *   Review of the sandbox goals for Phase 1.
    *   Ceremonial handoff of the **Regulator Takeaway Packet**.

*   **(10-30 min) Live Demo I: The Supervisory Control Plane (SCP) Cockpit**
    *   Walkthrough of the React-based Governance Dashboard.
    *   **Live View**: G-SRI, telemetry feeds, and system status (all GREEN).
    *   Demonstrate the OSCAL-based compliance matrix.

*   **(30-50 min) Live Demo II: From Telemetry to WORM Log**
    *   Trigger a minor, pre-planned anomaly (e.g., a small spike in model drift).
    *   Show the G-SRI twitch and the GSM state move from `Normal` to `Warning`.
    *   **Live CLI View**: Follow the `Decision Trace` as it's captured by the `pqc_worm_logger.py`.
    *   Show the signed, logged event in the S3 Object Lock bucket.

*   **(50-70 min) Live Demo III: The Independent Verification Flow**
    *   Switch to the **Regulator Verifier Node** perspective (a separate laptop/VM).
    *   Use a simple CLI tool to query the public Merkle log for the `Signed Tree Head (STH)`.
    *   Pull the **Evidence Pack** for the anomaly we just created.
    *   Run the verifier script, which checks the PQC signature and the ZK proof, returning `VERIFIED`.
    *   **TLA+ Toolbox Segment**: Briefly show the `SentinelContainmentProtocol.tla` spec and explain that the demonstrated state transition is formally verified to be safe.

*   **(70-85 min) Drills & Fallback Scenarios**
    *   Simulate a `Critical` event (`Red Dawn` scenario).
    *   Show the OmegaActual dead-man's switch engaging and the system moving to a `Halt` state.
    *   Demonstrate the GIEN heartbeat going red for the affected node.

*   **(85-90 min) Q&A and Next Steps**
    *   Review of the demonstrated capabilities.
    *   Outline the schedule for the next month's check-in.
