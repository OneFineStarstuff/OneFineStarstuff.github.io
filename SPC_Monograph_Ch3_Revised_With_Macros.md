# **A Foundational Monograph on the Semantic Preservation Calculus**\n## **Chapter 3 (Revised): The Category of Interpreted Systems**\n\n### **3.1 The Category of Interpreted Systems**\n\n**Definition 3.1.1 (Interpreted System).** An **interpreted system** is a pair `(X, I)` where `X` is a set and `I: X → S` is an interpretation into a semantic domain `S`. We will denote two arbitrary systems as `(X, I)` and `(Y, J)`.\n\n**Definition 3.1.2 (Morphism of Interpreted Systems).** Let `(X, I)` and `(Y, J)` be interpreted systems. A **morphism** `f: (X, I) → (Y, J)` is a function `f: X → Y` that preserves the semantic assignment, meaning:\n\n`x₁ \simI x₂ \implies f(x₁) \simJ f(x₂)`\n\nfor all `x₁, x₂ ∈ X`. This is equivalent to the condition `\simI ⊆ \sim_{J ∘ f}`.\n\n**Proposition 3.1.3 (Universal Property of Morphisms).** A map `f: X → Y` is a morphism `(X, I) → (Y, J)` if and only if the composite map `J ∘ f` factors uniquely through the canonical projection `\qI: X → X/{\simI}`.\n\n*Proof.* By definition, `f` is a morphism if and only if `J ∘ f` is constant on the `\simI`-equivalence classes. By the Universal Property of the Semantic Quotient (Corollary 2.2.2), this is precisely the necessary and sufficient condition for `J ∘ f` to factor uniquely through `\qI`. □\n\n**Corollary 3.1.4 (Quotient Morphism).** A map `f: X → Y` is a morphism `(X, I) → (Y, J)` if and only if there exists a unique map `f_S: X/{\simI} → Y/{\simJ}` such that the following diagram commutes:\n\n```mermaid\ngraph TD\n    X -- f --> Y;\n    X -- \qI --> X/{\simI};\n    Y -- \qJ --> Y/{\simJ};\n    X/{\simI} -.->|∃! f_S| Y/{\simJ};\n```\n*Commutativity: `\qJ ∘ f = f_S ∘ \qI`*\n\n*Proof.* Consider the composite map `g = \qJ ∘ f: X → Y/{\simJ}`. Let `x₁, x₂ ∈ X` such that `x₁ \simI x₂`. Since `f` is a morphism, this implies `f(x₁) \simJ f(x₂)`. By definition of `\qJ`, it follows that `\qJ(f(x₁)) = \qJ(f(x₂))`, which means `g(x₁) = g(x₂)` and `g` is a semantic invariant with respect to `I`. By the characterization of semantic invariants (Theorem 2.4.2), `g` must factor uniquely through `\qI`. This factorization provides the unique map `f_S: X/{\simI} → Y/{\simJ}` satisfying the commutative diagram. □\n\n**Theorem 3.1.5 (The Category `Interp`).** There exists a category, `\\mathbf{Interp}`, whose objects are interpreted systems and whose morphisms are as defined in 3.1.2. Composition is the standard composition of functions, and identities are identity functions.\n\n**Interpretation 3.1.6 (The Morphism Assignment of the Quotient Functor).** Corollary 3.1.4 provides the canonical translation of a morphism in `\\mathbf{Interp}` to a corresponding arrow in `\\mathbf{Set}`. This construction, `f ↦ f_S`, is precisely the assignment needed to define the action of our quotient functor on morphisms. The next section formalizes this.\n\n### **3.2 The Semantic Quotient Functor**\n\nWe now define the functor `Q` that maps each interpreted system to its canonical semantic representation.\n\n**Definition 3.2.1 (The Semantic Quotient Functor).** The **Semantic Quotient Functor**, denoted `Q: \\mathbf{Interp} → \\mathbf{Set}`, is defined as follows:\n- **On Objects:** `Q((X, I)) = X/{\simI}`.\n- **On Morphisms:** For a morphism `f: (X, I) → (Y, J)`, `Q(f) = f_S`, where `f_S` is the unique map whose existence is guaranteed by Corollary 3.1.4.\n
