# GIEN Governance Platform

A React + TypeScript foundation for the fictional GIEN / Omni-Sentinel governance mesh. This application is a supervisory workflow prototype, not a certified control system.

## Run locally

```bash
cd gien-platform
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Scope

- Role-oriented views for regulators, institutions / governance engineers, executive leadership, and research / education.
- Governance control domains CD-01 through CD-10.
- Systemic-risk indicator dashboard, compliance mapping, cryptographic-integrity evidence, digital-twin scenarios, scenario planner, submission packages, and long-horizon governance.
- Responsive navigation, accessible labels, and explicitly labelled demonstration data.

## Evidence and safety boundaries

All metrics displayed by the starter application are illustrative demonstration values. They are not live telemetry, validated measurements, compliance determinations, regulatory approvals, or independent assurance. Connect verified data sources and document provenance, freshness, ownership, and validation before using this interface operationally. Do not put credentials or private keys in client-side code.

## Architecture

- React 18, TypeScript, Vite
- Tailwind CSS with application-specific CSS
- React Router for page navigation
- Lucide React icons
- Recharts for visual analytics

The app is contained in `gien-platform/` so existing site content at the repository root is left intact.
