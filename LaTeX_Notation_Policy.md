# **Monograph LaTeX Notation Policy and Macro System**\n\n### **1. The Principle: A Two-Layer Macro System**\n\nTo ensure absolute notational consistency and facilitate global style changes, this monograph adopts a strict two-layer macro system. This system separates the semantic intent of the author from the final visual representation in the PDF.\n\n- **Layer 1: The Source Layer (Author-Facing).** Authors and editors MUST NOT write raw presentational code (e.g., `\sim_I`, `q_J`) in the main body of the text. Instead, they MUST use the semantic macros defined in this policy (e.g., `\simI`, `\qJ`). The source code should only reflect the mathematical meaning of the objects.\n\n- **Layer 2: The PDF Layer (Presentation-Facing).** A central macro file defines the expansion of the semantic macros into their final visual representation. To change the visual style of a symbol across the entire monograph, only a single line in the macro file needs to be edited. The PDF will only ever contain the fully expanded forms.\n\nThis policy enforces a complete and verifiable invariance between the semantic source and the visual output, eliminating the possibility of notational drift or contradiction.\n\n### **2.
